## Sales Performance Dashboard


## Overview
An Excel dashboard analysing 9,994 US retail transactions to identify revenue 
trends, regional performance, and product profitability, built on the Superstore 
retail dataset.

## Key Findings
- The West region leads on total sales ($725,457.82)
- Technology leads on profit margin (17.4%) despite Furniture generating comparable 
  revenue, at a much thinner 2.49% margin — a possible over-discounting issue
- Sales show a clear seasonal pattern, spiking in September, November and December 
  each year, consistent with a Q4/holiday shopping trend

## Tools Used
Microsoft Excel — pivot tables, charts, dashboard layout
